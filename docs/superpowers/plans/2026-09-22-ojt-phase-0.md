# OJT Progress Tracker Phase 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and verify the separated Vue/Laravel/MySQL technical foundation for the OJT Progress Tracker, stopping before all Phase 1 business features.

**Architecture:** Keep `frontend/` and `backend/` independent. The Vue app calls a single centralized Axios client, which reaches Laravel `GET /api/health`; Laravel is configured for MySQL through `.env` and exposes no feature modules yet.

**Tech Stack:** Vue 3, Vite, JavaScript, Vue Router, Pinia, Axios, Tailwind CSS, Laravel 12-compatible with PHP 8.2, PHPUnit/Pest default, Vitest, Vue Test Utils, jsdom, MySQL.
